# Center

`Box` preset with `align="center"` and `justify="center"` applied automatically. Perfect for loading states, empty states, icon containers, and anything that needs to be centred inside its parent.

## Preview

<PreviewPair>
<ComponentPreview>
  <Center w={160} h={100} bg="#f3f4f6" rounded={8}>
    <Box w={32} h={32} bg="#2563EB" rounded={16} />
  </Center>
</ComponentPreview>

```tsx
import { Center } from '@88khp/vajra-core';

<Center w={160} h={100} bg="#f3f4f6" rounded={8}>
  <Spinner />
</Center>
```
</PreviewPair>

## Usage

```tsx
import { Center } from '@88khp/vajra-core';

<Center flex={1}>
  <Spinner />
</Center>
```

## API

Accepts all [`Box` props](./box). The `align` and `justify` props are fixed and cannot be overridden.
