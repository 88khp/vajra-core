# Col

`Box` preset with `direction="column"` applied automatically. Use it for vertical stacks, form fields, card content, list items, settings rows, notification feeds.

## Usage

```tsx
import { Col } from '@88khp/vajra-core';

<Col gap={8} p={16}>
  <Title />
  <Subtitle />
</Col>
```

## API

Accepts all [`Box` props](./box). The `direction` prop is fixed to `"column"` and cannot be overridden.
